# LAST PIER · демонстрация

[Открыть демоверсию](https://bogolubov-creator.github.io/last-pier-demo/)

Здесь можно посмотреть карточки миров Solo, Duo и Unlimited, витрину, новости, кланы и пример регламента турнира. Цифры онлайна и примеры данных условные.

Сайт собран из React и TypeScript с помощью Vite. В `docs/` лежат готовые HTML, CSS и JavaScript. GitHub Pages публикует эту папку из ветки `main`.

## Установка на телефон

В Safari на iPhone открой меню «Поделиться» и выбери «На экран Домой». В Chrome на Android открой меню и выбери «Установить приложение» или «Добавить на главный экран».

После первого полного открытия с интернетом демокаталог и карточки товаров доступны без сети.

Переключатель RU / EN находится в шапке. Сайт запоминает выбранный язык и при открытии без сети.
